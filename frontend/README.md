# ForYou Frontend

React와 Vite로 구성된 ForYou 클라이언트입니다. 전체 개발 환경과 협업 규칙은
[루트 README](../README.md)를 참고하세요.

## 명령어

```bash
npm ci          # 의존성 설치
npm run dev     # 개발 서버 실행
npm run lint    # 정적 검사
npm run build   # 프로덕션 빌드
npm run preview # 프로덕션 빌드 미리보기
```

개발 서버의 기본 주소는 `http://localhost:5173`이며, `/api` 요청은
`http://localhost:8080`으로 전달됩니다.
